# Security

This is a read-only teleprompter for trusted local networks, not an Internet-facing service. Read `PRIVACY.md` before sharing speaker notes.

Do not include real presentation notes, access URLs/keys, screenshots containing confidential material, private IP addresses, or credentials in a public issue. Use a minimal synthetic example. If GitHub's private vulnerability reporting is available, prefer it for exploitable security defects.

Known boundaries: plain HTTP, bearer URLs, no per-device accounts, no remote revocation of content already displayed, and no protection from a privileged local user or an attacker controlling the network.
